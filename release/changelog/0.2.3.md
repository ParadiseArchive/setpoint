# Setpoint 0.2.3

Setpoint now runs on **Minecraft 26.1.2** too, the version of All the Mods 11, next to 26.3. Back up your world before you update.

## New

- **Minecraft 26.1.2:** a file of its own for 26.1.2 with NeoForge 26.1.2.109 or newer, with everything that is in the 26.3 one: every machine, the console, the P&IDs, the power grid, the operator gear and the showcase plant. Pick the file for your Minecraft version.
- On 26.1.2, water and lava flow round Setpoint's pipes, cables, valves and instruments instead of washing them away, as they do on 26.3.

## Changed

- Nothing changes for 26.3: the same mod, the same worlds.
